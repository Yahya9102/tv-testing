# Strömkontroller

Kontrollrapporterna skapas när GitHub Actions-jobbet **Kontrollera kurdiska TV-kanaler** körts.
Filerna `kurdistan-health.md` och `kurdistan-health.json` kommer att visa vilka
URL:er som svarade och om delar av videosegment kunde hämtas. Inga resultat
här är live-verifierade före den första körningen.

En lyckad HTTP-kontroll bevisar inte att kanalens innehåll kan avkodas på en TV
eller att en adress får distribueras fritt. Geoblockering och tillfälliga avbrott förekommer.
